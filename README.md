# Знахарница

Дизайн на сайт за продажба на бръмбара знахар — топъл, честен, „народно
лечителство от ново измерение“.

- **`index.html`** — целият сайт: Купи · Научи · Отзиви · Въпроси,
  форма за поръчка, светла и тъмна тема. Отваря се директно в браузър.
- **`DESIGN.md`** — палитра, типография, структура и бележки за интеграцията
  на плащанията (Stripe / SumUp).
